## 📖 About This Project
**NextRole** is a scalable, responsive job portal engineered to connect recruiters and job seekers. Built entirely from scratch using the MERN stack, this platform emphasizes backend security, clean architecture, and seamless user experiences. 

The backend is strictly structured using the **Model-View-Controller (MVC)** design pattern, featuring custom JWT authentication and Role-Based Access Control (RBAC). The frontend leverages **React** and **Redux Toolkit** to efficiently manage complex global state, such as dynamic job feeds and active user sessions across the platform.

## ✨ Key Features
* **Role-Based Dashboards:** Distinct UI and authorization flows for `Recruiters` (posting/managing jobs) and `Applicants` (searching/applying for jobs).
* **Custom Authentication:** Secure, from-scratch user authentication and session management using JWT and bcrypt password hashing.
* **Global State Management:** Seamless synchronization of application data, job feeds, and user profiles using Redux Toolkit.
* **Advanced Filtering:** Dynamic search and filtering mechanisms for precise job discovery.
* **Secure API Integration:** Custom CORS policies and environment-driven variables securely interfacing with a MongoDB Atlas cluster.
